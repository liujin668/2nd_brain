Compilation and Simulation
Having run the code generator successfully, you can then run a simulation as
follows:
Cadence:
cd <project>/sim
./compile_ius.sh
Mentor:
cd <project>/sim
vsim -c -do "do compile_questa.do; run -all"
Synopsys:
cd <project>/sim
./compile_vcs.sh
